T.A.N.K. Android - GitHub APK Build

1. Create a new GitHub repository (for example: TANK-Android).
2. Upload all files in this project to the repository root.
3. Open the repository's Actions tab.
4. Select "Build Android APK".
5. Click "Run workflow" and select the main branch.
6. Wait for the green check mark.
7. Open the completed workflow run.
8. Under Artifacts, download "TANK-Android-debug-apk".
9. Extract the downloaded ZIP; it contains app-debug.apk.

The workflow also builds automatically whenever you push to main/master.

The workflow installs Gradle 8.9 and uses Java 17. No Gradle wrapper is required.
